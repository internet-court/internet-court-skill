## How to read the Copyright column

Every value in that column is transcribed from the `LICENSE` file **as this
package actually ships it**, not from the upstream project's website, its
`package.json`, or its GitHub owner name. That is deliberate: a downstream
redistributor's attribution obligation runs to the notice in the licensed file
it received, so the manifest has to mirror that file even when the file looks
wrong. Where a license names no holder, the column says so instead of guessing
one.

**Note 1 — upstream notices that name an unrelated project.** Some vendored
skills ship a `LICENSE` whose copyright line belongs to a different project
than the one that published the skill, because the upstream repository itself
copied a license file from elsewhere. Two cases are recorded above:
`alkahest-*` carries the Forge Standard Library notice and `*-git-escrow`
carries the napi-rs notice, both in repositories owned by Arkhai. The grant
text is MIT in both cases and is unaffected; only the attribution line is
questionable. The rows reproduce what the shipped file says. These are reported
upstream, and the rows will be corrected here when the upstream files are.

**Note 2 — Apache-2.0 with an unfilled appendix.** The Apache-2.0 boilerplate
carries no copyright holder of its own; the holder goes in the
`[yyyy] [name of copyright owner]` appendix, which these upstreams left blank.
The phrase *"the copyright owner that is granting the License"* appearing in
such a file is part of Apache-2.0's definition of **Licensor**, not an
attribution — do not transcribe it as one.

## About `LicenseRef-NoLicense`

That marker is **not a license**. It records that the upstream project
publishes no license and states no terms: all rights remain with the
original author, and this package asserts none. Those skills are
redistributed only because the work is published publicly and listed in
an official catalogue; each one's `LICENSE` file names the upstream as
authoritative and records the basis in full.

If you are the copyright holder of one of these and want it removed or
placed under stated terms, open an issue at
<https://github.com/internet-court/internet-court-skill> — removal
requests are honoured without argument.
